# Program 1: AI Model Trainer - 설명 문서

## 이 프로그램은 무엇인가?

이 프로그램은 제품 표면의 결함을 자동으로 검출하는
AI 모델을 **학습(Training)하고 평가(Evaluation)하기 위한 도구**입니다.

웹 브라우저에서 실행되며 사용자는 코드를 작성하지 않고도

- 데이터 확인
- 모델 학습
- 모델 성능 평가
- 모델 Export

를 수행할 수 있습니다.

이 프로그램의 목적은 **AI 기반 검사 시스템 개발을 단순화하는 것**입니다.

---

# 배경 지식 (Background Knowledge)

## 인공지능(AI)이란?

인공지능은 컴퓨터가 데이터를 통해 학습하고
스스로 판단을 내릴 수 있도록 하는 기술입니다.

예를 들어 사람이 수천 개의 제품을 보면서
불량을 구분하는 방법을 배우듯이

AI 모델도 **수천 장의 이미지를 학습하면서 결함을 인식하는 방법을 배웁니다.**

---

## Dataset이란?

Dataset은 AI를 학습시키기 위한 이미지 데이터 집합입니다.

이 프로젝트에서는 **MVTec AD Dataset**을 사용합니다.

MVTec AD Dataset은 산업용 결함 검출 연구에서
세계적으로 가장 많이 사용되는 데이터셋 중 하나입니다.

### Dataset 정보

- 총 이미지 수: **5,354**
- 카테고리: **15개**
- 각 이미지에는 결함 위치가 라벨링 되어 있음

---

## 왜 MVTec AD Dataset을 사용하는가?

MVTec AD Dataset은 실제 산업 환경에서 발생하는
표면 결함 상황을 잘 반영하는 데이터셋입니다.

이 데이터셋의 특징

- 매우 작은 표면 결함
- 불규칙한 결함 형태
- 조명 변화
- 실제 산업 제품 이미지

이러한 이유로 산업용 비전 연구에서
**표준 Benchmark Dataset**으로 사용됩니다.

---

## YOLO란?

YOLO는 **You Only Look Once**의 약자입니다.

이미지에서 객체를 탐지하는 매우 빠른 알고리즘입니다.

기존 방식은 이미지를 여러 번 분석하지만
YOLO는 **이미지를 한 번만 분석하여 모든 객체를 탐지합니다.**

그래서 매우 빠른 속도를 가집니다.

이 프로젝트에서는 **YOLOv8**을 사용합니다.

---

## 왜 산업 검사에서 YOLO를 사용하는가?

산업 생산 라인에서는 제품이 계속 이동하기 때문에
검사 시스템이 **매우 빠르게 판단해야 합니다.**

YOLO는 다음과 같은 장점을 가지고 있습니다.

- 이미지 전체를 한 번에 분석
- 실시간 검사 가능
- 속도와 정확도의 균형
- CPU 환경에서도 실행 가능

이러한 이유로 YOLO는 다음과 같은 산업 검사에 사용됩니다.

- 자동차 부품 검사
- PCB 검사
- 병(Bottle) 검사
- 반도체 검사

---

## ONNX란?

ONNX는 **Open Neural Network Exchange**의 약자입니다.

AI 모델을 여러 언어에서 사용할 수 있도록 만들어주는
표준 모델 포맷입니다.

예를 들어

Python에서 학습한 모델을

- C#
- C++
- Java

프로그램에서도 사용할 수 있습니다.

이 프로젝트에서는 학습된 모델을 **ONNX로 변환하여**
C# 검사 프로그램에서 사용합니다.

---

## Neural Network란?

Neural Network는 인간의 뇌 구조에서 영감을 받은
수학적 모델입니다.

여러 개의 **Layer(층)**로 구성되어 있으며
각 층은 이미지의 특징을 추출합니다.

예를 들어

초기 Layer

- Edge
- 선

중간 Layer

- 형태
- 패턴

마지막 Layer

- Crack
- Contamination

같은 결함을 인식합니다.

---

## Training이란?

Training은 AI 모델을 학습시키는 과정입니다.

학습 과정

1. 모델이 이미지를 확인
2. 결함 위치를 예측
3. 실제 정답과 비교
4. 오차 계산
5. 모델 파라미터 수정

이 과정을 수천 번 반복하면서
모델의 정확도가 높아집니다.

---

## GPU란?

GPU는 원래 그래픽 처리를 위해 만들어진
연산 장치입니다.

하지만 AI 학습에서 필요한

- 행렬 연산
- 병렬 연산

을 매우 빠르게 처리할 수 있습니다.

그래서 AI 학습은 GPU를 사용하면
**CPU보다 10~100배 빠르게 진행됩니다.**

이 프로젝트는 **Google Colab T4 GPU**를 사용합니다.

---

## GradCAM이란?

GradCAM은 AI 모델이 이미지의 **어느 부분을 보고 판단했는지**
시각적으로 보여주는 기술입니다.

예를 들어

병에 Crack이 있을 때

GradCAM Heatmap을 통해
모델이 실제로 **Crack 위치를 보고 판단했는지 확인할 수 있습니다.**

---

## Explainable AI가 중요한 이유

산업 검사에서는 AI가 **올바른 위치를 보고 판단하는지**
확인하는 것이 매우 중요합니다.

예를 들어

모델이 결함이 아닌 **배경을 보고 판단한다면**
실제 생산 라인에서 사용할 수 없습니다.

GradCAM은 이러한 문제를 확인할 수 있게 해줍니다.

예시

- 유리 병 검사
- 반도체 웨이퍼 검사
- 자동차 부품 검사
- PCB 검사
- 금속 표면 검사
